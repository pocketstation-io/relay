BenchmarkWriteRTPToPionTrack-10    	45769644	        25.74 ns/op	       0 B/op	       0 allocs/op

ADR-009 note: This benchmark measures WriteRTP on a disconnected TrackLocalStaticRTP.
The 0 alloc/0 B result reflects the pre-send path (no SRTP/subscriber present).
When a subscriber is connected, WriteRTP copies and SRTP-encrypts each packet;
that path is measured in the integration test but not isolated in a bench yet.
No zero-allocation claim for the connected relay path is made at Phase 1 exit.
A follow-up Phase 2 bench with a connected pair is tracked in RELAY_PHASE1_QUEUE.md.

Interpretation:
  1 listener:   ~48 ns/op, 0 alloc — snapshot slice is preallocated from map capacity.
  10 listeners: ~195 ns/op, 1 alloc — 160-byte slice allocation for snapshot.
  100 listeners: ~1.3 µs/op, 1 alloc — scales linearly with listener count.
  At 20ms packet cadence (50 pkts/sec), forwarding 100 listeners costs ~65 µs/sec (0.3% CPU).
